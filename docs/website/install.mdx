## CLI

The installer downloads the latest stable release for your operating system and architecture.

<Tabs>
  <TabItem label="macOS and Linux">
    ```sh
    curl -fsSL https://tui-test.dev/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://tui-test.dev/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

### Homebrew

```sh
brew tap microsoft/tui-test https://github.com/microsoft/tui-test
brew install tui-test
```

You can also download platform archives from [GitHub Releases](https://github.com/microsoft/tui-test/releases).

### Verify the installation

```sh
tui-test --version
```

If your shell cannot find `tui-test`, restart the terminal or check that the installation directory is on your `PATH`.

## Libraries

Library sessions run in your process and do not require the CLI.
